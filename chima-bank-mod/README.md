# ちま銀行 MOD (chima-bank-mod)

「ちま銀行券」4種類(百円・千円・五千円・壱万円)と、ネザライト相当の性能を持つ
「銀行家シリーズ」の防具・武器を追加し、村人の新職業「銀行員(banker)」経由で
紙幣⇔素材・紙幣⇔紙幣・紙幣⇔装備の売買(両替)ができるMinecraft Fabric MODです。

## 対象バージョン
- Minecraft: 1.20.1
- Fabric Loader: 0.15.11 以上
- Fabric API: 0.92.2+1.20.1
- Java: 17 以上

## 追加される中身

### 紙幣(アップロードされた最新画像のデザイン)
- `chimabank:note_100` 百円
- `chimabank:note_1000` 千円
- `chimabank:note_5000` 五千円
- `chimabank:note_10000` 壱万円

### 銀行家シリーズ(ネザライトと同じ性能。アイコンに「ちま銀行」の赤いスタンプ付き)
- 剣・ツルハシ・斧・シャベル・クワ
- 弓・トライデント
- ヘルメット・チェストプレート・レギンス・ブーツ
- エリトラ

### ブロック・村人
- `chimabank:money_counter` … 銀行員の仕事場ブロック
- 銀行員(banker)の職業 … `money_counter` の近くにいる無職の村人が就職します

## 取引内容(村人のレベルが上がるほど品揃えが増えます)
| レベル | 内容 |
|---|---|
| 1 見習い | ダイヤ⇔壱万円札、鉄⇔千円札、紙幣同士の両替(100↔1000↔5000↔10000) |
| 2 見習い上位 | ヘルメット・ブーツ・クワ・シャベル(各 五千円) |
| 3 一人前 | 剣・斧・ツルハシ・弓(各 壱万円) |
| 4 熟練 | チェストプレート・レギンス(各 壱万円×2) |
| 5 達人 | トライデント・エリトラ(各 壱万円×2、在庫少なめ) |

村人と繰り返し取引すると経験値が貯まってレベルアップし、次の段階の品揃えが解放されます
(バニラの村人と同じ仕組みです)。

## 見た目についての制限(重要)
- 銀行家シリーズの**道具・武器・防具アイコン**は、バニラのネザライト装備のアイコンに
  赤いスタンプ画像を重ねた見た目になっています。
- **防具を装備した時の見た目**は専用テクスチャ
  (`textures/models/armor/chimabank_banker_layer_1.png` / `_layer_2.png`)を
  参照するようにしてあり、金色っぽい色味に変わります。ただし本物のネザライト防具の
  形状データ(UVテンプレート)は同梱していないため、簡易的な単色+斜め模様のテクスチャです。
  より精巧な見た目にしたい場合は、上記2枚のPNG(64×32)をお好みの絵に差し替えてください。
- **エリトラを装備した時の背中の見た目**は、バニラのエリトラ描画コードがアイテムデータではなく
  固定のテクスチャファイルを参照する仕様のため、追加のクライアント側描画コードなしでは
  差し替えられません。今回はアイコンのみ変更し、装備中の見た目はバニラのエリトラのままです。
  差し替えたい場合はFabric APIの `ArmorRenderer` 等を使った追加実装が必要です。
- 弓・トライデントは「構える/投げる」時の専用モーション用モデルは用意していないため、
  アイコンは変わりますが構えた時のモーションはバニラと同じ挙動になります。

## ビルド方法
1. [Java 17 (Temurin推奨)](https://adoptium.net/) をインストール
2. このフォルダを、パスに日本語や空白を含まない場所に展開する
3. フォルダをIntelliJ IDEAで開く(File > Open)と Gradle Wrapper が自動生成されます。
   IDEを使わない場合は、フォルダ内で `gradle wrapper --gradle-version 8.6` を一度実行してください
   (事前にGradle本体のインストールが必要です)。
4. ターミナルでプロジェクトフォルダに入り、以下を実行します。

```
# Windows
gradlew.bat build

# macOS / Linux
./gradlew build
```

5. ビルドが成功すると `build/libs/chima-bank-mod-1.0.0.jar` が生成されます。

## ゲーム内での使い方
1. Fabric Loader・Fabric APIを導入したMinecraft 1.20.1に、上記でビルドしたjarを
   `.minecraft/mods` に入れて起動します。
2. クリエイティブの「道具・材料」タブに紙幣4種、「機能ブロック」タブに「両替カウンター」、
   「戦闘」「道具」タブに銀行家シリーズの装備が追加されています。
3. `money_counter` ブロックを設置し、無職の村人を近くに連れて行くと「銀行員」に転職します。
4. 銀行員と取引すれば、紙幣・ダイヤ・鉄・装備を売買できます。

## CurseForgeへのアップロードについて
このMOD自体はFabricの標準的な仕組みだけで作ってあるので、**追加の対応は不要**で
そのままCurseForgeに公開できます。手順は以下の通りです。

1. `./gradlew build` で作った `build/libs/chima-bank-mod-1.0.0.jar` を用意する
   (`-sources.jar` の方はアップロード不要です)。
2. [CurseForge for Minecraft](https://legacy.curseforge.com/minecraft/mc-mods) に
   ログインし「Create Project」からMOD用プロジェクトを作成する。
3. プロジェクト作成時に以下を設定します。
   - Project Type: **Mod**
   - Loader: **Fabric**
   - Categories: 好きなもの(Armor, Tools, Economy など)を選択
4. 「Files」→「Upload a File」で、手順1のjarをアップロードします。アップロード時に
   - Game Version: **1.20.1**
   - Mod Loader: **Fabric**
   - Relations(依存関係)に **Fabric API** を「Required Dependency」として追加してください
     (このMODはFabric API必須のため)。
5. プロジェクトの説明文・アイコン・スクリーンショットはCurseForgeの管理画面から別途設定します
   (jarの中身とは無関係なので、今回のコードには含めていません)。
6. 審査(自動+手動チェック)が通れば公開されます。

同じjarをModrinthに公開したい場合も、手順はほぼ同じです(Modrinthの方が審査が早いことが多いです)。

## 補足
- Minecraft/Fabric APIはマイナーバージョンごとにクラス名やメソッドのシグネチャが変わることがあります。
  特に `ArmorMaterial` や `TradeOffer` 周りはバージョン差が大きいため、コンパイルエラーが出た場合は
  Fabric Wikiの「Custom Armor」「Villager」チュートリアルと照らし合わせて調整してください。
- このMODはサンドボックス環境(Minecraft/Fabricの配布サーバーに接続できない環境)で作成したため、
  実機でのビルド確認はできていません。上記手順でビルドしてご確認ください。
